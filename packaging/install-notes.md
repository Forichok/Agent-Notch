
### Install

```bash
brew install --cask forichok/tap/agent-notch
```

Or download the DMG below and drag **Agent Notch** to Applications. The app is open source and not notarized yet, so macOS blocks the first launch of a downloaded copy. Either run `xattr -dr com.apple.quarantine "/Applications/Agent Notch.app"`, or open it once, then go to System Settings → Privacy & Security and click **Open Anyway**. Homebrew does this step for you.

Requires macOS 14 Sonoma or later on Apple Silicon.

The agents' house screen saver is `AgentNotchHouse-<version>.saver.zip` (also in the DMG): double-click `Agent Notch House.saver` to install it, or use Settings → Desktop house → Screen saver in the app.
